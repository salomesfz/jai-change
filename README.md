# DND — J'ai changé ? 🪞

> Expérience immersive de pré-sauvegarde pour le prochain single de **DND** : *"J'ai changé ?"*.

---

## 🌟 Le Concept

À l'ouverture du site, le visiteur se retrouve devant un miroir embué dans une ambiance feutrée et sombre (lumières tamisées de loge / salle de bain). 
Sur le miroir sont collés :
- Des **photos polaroid de DND** scotchées au miroir.
- Un **sticker "dnd"** au style typo fait main.
- Un **post-it bleu** avec la question manuscrite : *"et toi, tu vois quoi quand tu te regardes dans le miroir ?"*.
- Une invitation interactive incitant le visiteur à **désembuer le miroir avec son doigt** (sur smartphone) ou la souris (sur ordinateur).
- En essuyant la vapeur, il découvre le titre du single **"J'AI CHANGÉ ?"** et le lien de **pré-sauvegarde** multiplateforme (Spotify, Apple Music, Deezer, YouTube Music).

## 🚀 Mise en ligne gratuite sur GitHub Pages

Pour que le site soit accessible en direct à tous vos fans sur Internet :
1. Rendez-vous sur votre dépôt : [github.com/salomesfz/jai-change/settings/pages](https://github.com/salomesfz/jai-change/settings/pages)
2. Sous **Build and deployment > Branch** :
   - Sélectionnez la branche **`main`**
   - Laissez le dossier sur **`/(root)`**
   - Cliquez sur **Save**
3. En quelques instants, votre site sera en ligne à l'adresse :  
   👉 **`https://salomesfz.github.io/jai-change/`**
